What are Custom Attribute Mappings?

Custom attribute mappings allow you to define user attribute requirements for accessing specific endpoints. This enables fine-grained access control based on user properties stored in Keycloak.

Example: To limit agent chat access to users in the "engineering" department, create a mapping for endpoint /api/v1/chat/** with attribute department=engineering.
