Pluggable Rule Configuration

Configure "[[${ruleName}]]". Define a custom rule using Spring Expression Language (SpEL).
This rule will evaluate commands in SSH/RDP sessions based on your expression.
Available Variables:
  • #text - The command/input text being evaluated
  • #length - Length of the text
  • #isEmpty - Boolean indicating if text is empty
  • #isBlank - Boolean indicating if text is blank
Available Methods on #text:
  • #text.contains('string') - Check if text contains substring
  • #text.startsWith('string') - Check if text starts with string
  • #text.endsWith('string') - Check if text ends with string
  • #text.toLowerCase(), #text.toUpperCase() - Convert case
  • #text.matches('regex') - Match against regular expression
Operators: and, or, !, >, <, >=, <=, ==, !=
Rule Configuration
Enter a SpEL expression that evaluates to true when the rule should trigger.
Select what action should be taken when the rule triggers.
This message will be shown to users when the rule triggers.
Enable sanitization for sensitive pattern matching (recommended).
Examples

Expression: #text.toLowerCase().contains('sudo')
Action: DENY
Description: Sudo commands are not allowed

Expression: #text.startsWith('rm ') or #text.contains(' rm ') or #text.contains('rmdir')
Action: WARN
Description: Delete operation detected
This matches rm at the start or as a separate word

Expression: #text.contains('passwd') or #text.contains('password')
Action: JIT
Description: Password changes require approval

Expression: #length > 100
Action: DENY
Description: Commands exceeding length limit are not allowed
